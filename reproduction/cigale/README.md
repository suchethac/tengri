# CIGALE reproduction study

This notebook (`01_cigale.py`) verifies that tengri reproduces the physics surface of CIGALE (Boquien et al. 2019, A&A 622, A103).

## What's here

- **`01_cigale.py`** — Main reproduction notebook (jupytext percent format). Component-by-component comparison: SSP templates, SFH models, nebular emission, dust attenuation, dust IR, AGN, X-ray, radio, and IGM. Cites every model and flags gaps.

- **`_drivers/`** — Thin wrappers around pcigale for concise notebook cells:
  - `units.py` — Unit conversions between CIGALE (W/nm on nm wavelengths) and tengri (erg/s/Hz on Angstroms).
  - `cigale_driver.py` — Instantiate pcigale modules and extract SEDs, attenuation curves, and SFH curves.
  - `cigale_ssp_to_dsps.py` — One-off script: reads CIGALE's BC03 FITS files and writes the shared `bc03_from_cigale.h5`.

- **`_drivers/data/bc03_from_cigale.h5`** — Shared BC03 templates in DSPS HDF5 schema. Both pcigale and `tengri.load_ssp()` consume this file identically, so any §1 SSP residual is interpolation error only.

- **`_figs/`** — Output figures (generated on notebook execution).

## Regenerating BC03 templates

The `bc03_from_cigale.h5` file was generated by `_drivers/cigale_ssp_to_dsps.py`:

```bash
python _drivers/cigale_ssp_to_dsps.py \
  --input /path/to/.venv/lib/python3.12/site-packages/pcigale/data/bc03/ \
  --output _drivers/data/bc03_from_cigale.h5
```

This reads CIGALE's `bc03_*.fits` files (Chabrier IMF, 6 metallicities, full age grid) and writes an HDF5 file with:
- `ssp_lg_age_gyr` — log10(age / Gyr), shape (13700,)
- `ssp_lgmet` — log10(Z), shape (6,)
- `ssp_wave` — rest-frame wavelength in Angstroms, shape (1262,)
- `ssp_flux` — stellar luminosity L_λ [W/m³], shape (13700, 6, 1262)

Both `pcigale.sed_modules.bc03` and `tengri.load_ssp()` read from this file with no modifications.

## Notebook structure

1. **Title + framing** — One paragraph introducing the comparison.
2. **Setup** — Imports and style.
3. **Capability map** — Registry entries and CIGALE module → tengri equivalence table.
4. **§1 SSP** — BC03 Chabrier Z=Zsun spectra at five ages.
5. **§2–§4 SFH, stellar SED, nebular** — Each layer in isolation, fiducial parameters.
6. **§5–§6 Dust attenuation** — Curves and applied attenuation.
7. **§7–§9 Dust IR** — DL2007, DL2014, Dale2014.
8. **§10–§12 AGN, X-ray, radio** — AGN viewing angle / X-ray column / radio q_IR.
9. **§13 IGM redshifting** — Inoue+2014 vs Meiksin 2006.
10. **Gaps** — Markdown list with issue references.

## Voice and conventions

- **Scientist-to-scientist tone** — No "Let's", "We will", "Notice that". Declarative.
- **Cells short** — 3–8 lines; bookkeeping lives in `_drivers/`.
- **Every panel labeled** — `pcigale.sed_modules.<name>` vs `tengri.<path>`.
- **Same axes** — Log-log wavelength vs L_ν, shared y-limits, same units.
- **Citations at point of use** — E.g., "Boquien+2019" inline, not a References section.
