# Reproducing ProSpect's physics with tengri

This folder places **ProSpect** (Robotham et al. 2020, MNRAS 495, 905) next to
tengri component by component — same parameters, same units, same stellar
library family, one figure per physics block.

ProSpect is an R package. Unlike the CIGALE and Prospector reproductions, whose
engines are Python, ProSpect runs in R and is driven here **live from the
notebook through `rpy2`**: every left-hand panel is ProSpect's own output,
generated by calling its R functions in-process and reading the result back as
NumPy. The right-hand panel is tengri.

ProSpect's forward model is built on the Bruzual & Charlot (2003) and EMILES
stellar libraries, Charlot & Fall (2000) two-component dust attenuation, the
Dale et al. (2014) infrared dust templates, Fritz et al. (2006) and SKIRTOR AGN
torus libraries, and Inoue et al. (2014) IGM absorption. Its distinguishing
feature is a **metallicity history tied to the cumulative stellar mass formed**
(Bellstedt et al. 2020) — the `Zfunc_massmap_lin` / `Zfunc_massmap_box`
closed-box models — which §2b examines directly.

## Files

- **`01_prospect_r.py`** — the notebook, jupytext percent format.
- **`_drivers/`** — code-side glue:
  - `units.py` — ProSpect (L⊙/Å) ↔ tengri (erg/s/Hz). Ships
    `verify_unit_conversion(rtol=1e-3)`; the notebook trips at Setup if the
    converter ever drifts.
  - `prospect_driver.py` — thin `rpy2` wrappers around ProSpect's R functions
    (`SFHfunc`, `ProSpectSED`, `massfunc_*`, `Zfunc_*`, `CF_screen`,
    `Dale_interp`, the AGN and IGM blocks), returning SSPs, composite SEDs,
    SFHs, metallicity histories, and dust / AGN / IGM curves in tengri's units.
    The ProSpect stellar/dust/AGN data libraries load once and are cached at
    module level.
  - `data/` — scratch space, git-ignored; ProSpect's template libraries live
    inside the R package (`ProSpectData`), not here.
- **`_figs/`** — generated figures.

## Prerequisites

ProSpect and its data package are installed from GitHub inside R:

```r
install.packages(c("remotes", "celestial", "Rcpp", "foreach", "magicaxis"))
remotes::install_github("asgr/ProSpectData")
remotes::install_github("asgr/ProSpect")
```

and the Python bridge plus notebook tooling:

```bash
pip install rpy2 jupytext jupyter
```

`rpy2` builds against the R installation found on `PATH`; make sure `R` and
`Rscript` resolve before installing it.

## Running

```bash
jupytext --to ipynb 01_prospect_r.py
jupyter nbconvert --to notebook --execute 01_prospect_r.ipynb
```

The first ProSpect call loads the stellar + dust template libraries (a few
seconds); they are cached for the rest of the run.

## What the notebook covers

§1 stellar populations (BC03) · §2 star formation history (skew-normal,
delayed-τ) · §2b metallicity history (mass-mapped chemical evolution) ·
§3 integrated stellar SED · §4 dust attenuation (Charlot & Fall) · §5
attenuation applied · §6 dust IR re-emission (Dale 2014) · §7 panchromatic SED ·
§8 nebular emission · §9 AGN torus · §11 radio continuum · §12 IGM transmission
(Inoue 2014) · full-SED head-to-head.

The library overlap is not exact, and the notebook is explicit about where it
is not: ProSpect's EMILES library and Fritz (2006) torus have no tengri
equivalent, and ProSpect's mass-mapped metallicity history maps onto tengri's
time-based and closed-box modes only approximately. Each gap is quantified in
its section rather than smoothed over.
