# Paper I Figure Scripts

These scripts generate the main figures for the tengri methods paper.
They are the production-ready versions; the actively maintained equivalents
are in `analysis/fig04_*` through `analysis/fig08_*`.

| Script | Paper Figure | Description |
|--------|-------------|-------------|
| A01_mock_program.py | Fig 2-3 | PSD → SFH schematic, mock generation |
| A02_sfh_recovery.py | Fig 5-6 | Individual galaxy SFH recovery |
| A03_population_psd.py | Fig 7 | Hierarchical population-level PSD |
| A04_benchmarks.py | Fig 8, 10 | Wall-clock timing benchmarks |
| A05_gradient_sensitivity.py | Fig 4, 9 | Jacobian heatmaps, scalograms |

The T-series files (T00--T06) are intermediate tutorial drafts that evolved
into the current `notebooks/tutorials/` and `notebooks/demonstrations/` notebooks.
