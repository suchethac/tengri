# Paper I figures, reproducible

Every figure in the paper, regenerated by one command:

```
python paper1_figures/regenerate.py
```

That command is the acceptance test. If it exits zero, every figure the paper
prints can be rebuilt from committed data by someone who has only this
repository.

## How it is arranged

- `notebooks/` — one notebook per figure family, in jupytext percent format.
  They are valid Python scripts as well as notebooks, which is why
  `regenerate.py` can run them headless with neither jupyter nor nbconvert.
- `figures/` — output. **Not committed**: `.gitignore` excludes `fig*.pdf` and
  `tools/check_tracked_not_ignored.py` enforces it. The committed artifact is
  the notebook plus the data it reads, so a stale PDF cannot sit in the tree
  disagreeing with the numbers.

The `.ipynb` files are not committed either, only the `.py`. The largest
tracked files in this repository are already notebooks of several MiB that are
almost entirely base64 PNG, and `tools/check_file_sizes.py` ratchets on that.

## Two rules these notebooks follow

**They call the committed scripts; they do not reimplement them.** A notebook
that redraws a figure is a second copy of the plotting logic, and the two
drift. `analysis/paper1/` holds the renderer and is the single source of
truth; a notebook here loads the data, calls it, and explains the result.

**They read `analysis/paper1/results/` and never copy data in.** Two copies of
a results file is how a figure and its caption come apart.

## Notebooks

| notebook | figures | data |
|---|---|---|
| `01_gpu_performance.py` | datacenter and consumer GPU scaling | `sherlock_h100_batch.json`, `consumer_gpu_batch.json` |

Further families (precompute accuracy, the mock joint inference, the CANDELS
grid) are added as their data lands; each follows the same shape.

## What the figures may not be used to claim

Each data file carries its own `caveats` block and the notebooks print it, so
the limits travel with the numbers rather than living in someone's memory. For
the GPU pair the important one is that a per-galaxy cost measured inside the
launch-latency floor is a lower bound that is still falling, not an asymptote.
