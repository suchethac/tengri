Examples
========

Standalone example scripts demonstrating tengri's capabilities.
Each script is self-contained, produces one figure, and can be run directly::

    python examples/quickstart/plot_first_fit.py

Most physics examples (dust curves, SFH shapes) need only tengri's core
dependencies. Fitting examples additionally require SSP data at
``data/ssp_fsps_v3.2.h5``.
