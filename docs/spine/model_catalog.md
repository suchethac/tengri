# Model Catalog

Every physics module tengri ships, its sub-physics, and each implemented model, experimental ones included. The wheel is built from the live registries on every docs build, so a newly registered model appears here without a documentation edit. Click a module or group to zoom in, and click a model for its reference. The hub, or Esc, zooms back out. The tables behind the wheel are on the [component reference](../components.md) page, and [Discovering the menu](03_discovering_the_menu.ipynb) shows how to list them from Python.
