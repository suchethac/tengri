# Introduction

This catalog documents the physical model components implemented in this version of tengri, a differentiable modular framework for Bayesian galaxy spectral energy distribution (SED) fitting. It serves as the source of truth for the exact formulation, parameters, and priors of each physics block in the framework, and is maintained alongside the code repository.

The tengri framework decouples physics from inference by composing independent modules: stellar populations, metallicity and alpha-element enhancement, star formation histories, dust attenuation and emission, nebular and AGN emission, IGM absorption, and radio/X-ray components. Each module is mathematically precise, selectable at configuration time, and checked against reference implementations. The forward model is fully differentiable and gradient-aware, enabling direct comparison of inference backends, point estimation, MCMC sampling, variational inference, on identical problems.

For the complete framework architecture, design principles, and inference methodology, please refer to the companion framework paper (Cooray, in prep.). That work describes the standardized latent-coordinate parameterization, the precomputation strategy for fast gradient evaluation, and demonstrations on real galaxy data.

**Organization of this catalog.** Each section below covers one physics block: stellar population synthesis, metallicity parameterization and alpha-element enhancement, star formation histories, dust attenuation and emission, nebular emission, AGN emission, multi-wavelength extensions including radio and X-ray, IGM absorption, observation models, and the computational framework. Each section contains the mathematical formulation, free parameters with their priors, and notes on the reference implementation. A parameter reference table appears at the end.

**Living document and versioning.** This catalog is regenerated at each tengri release to reflect the code as it stands at that point. The version number corresponds to the framework release tag and is recorded at the top of the document. Although the model components are expected to evolve as the community contributes improvements, backward compatibility and deprecation policies are defined in the framework repository to ensure reproducibility. For reproducible results, always cite this document with its version; the framework paper cites the version current at the time of writing.

**Relationship to code documentation.** The authoritative source for model registries and algorithms is the code repository, specifically the modules under `tengri.models.*` and the configuration registry. The documentation pages in the repository are generated from the same sources as this PDF and provide interactive access to the same information. A user seeking implementation details or trying to port a model to another framework should consult both this document and the code.
