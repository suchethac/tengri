# Contributing to tengri

> Quick reference for agents and developers making changes.

## Before You Start

1. Read `docs/ARCHITECTURE.md` — understand the module map and standardization principle
2. Read `CLAUDE.md` — gotchas, commands, conventions
3. Read `HANDOFF.md` — current status and what needs doing

## Environment

```bash
cd ~/Projects/tengri
source .venv/bin/activate
pytest tests/ -q              # 302 tests, ~50s
```

## Making Changes

### Adding a new prior distribution

1. Subclass `Distribution` in `src/tengri/distributions.py`
2. Implement: `bounds`, `sample()`, `log_prob()`, `unstandardize()`, `standardize()`
3. `unstandardize()` MUST be JAX-differentiable — test with `jax.grad`
4. Add to `__init__.py` exports
5. Add tests in `tests/unit/test_distributions.py`
6. Run: `pytest tests/unit/test_distributions.py -v`

### Adding a new inference method

1. Add `_run_METHOD()` to `Fitter` in `src/tengri/fitter.py`
2. Route in `Fitter.run()` method
3. Return a `Posterior` object
4. Add tests in `tests/unit/test_fitter.py`
5. Use lazy imports for optional dependencies

### Adding a new PSD model

1. Write a function: `def my_psd(sigma, tau_yr, n_grid, log_ages) -> sqrt_power`
2. Pass to `StandardizedForwardModel(model, psd_model=my_psd)`
3. The function must be JAX-differentiable (for gradient-based inference)

### Modifying the forward model

1. Changes go in `src/tengri/model.py` (high-level) or `src/tengri/forward_model.py` (low-level)
2. The `_correlated_field` key in params dict bypasses internal GP — don't break this
3. Test both stochastic and non-stochastic modes
4. Verify gradients: `jax.grad(lambda p: model.predict_photometry(p)["some_param"])`

### Modifying the paper

1. Draft location: `~/writing-workspace/projects/differentiable_psd_sed_fitting/`
2. Compile: `latexmk -pdf 0-ms.tex`
3. Figures generated by: `python analysis/fig0X_*.py`
4. Paper I = methods + mock recovery. Paper II = real data.

## Testing

```bash
# Full suite
pytest tests/ -q

# Specific module
pytest tests/unit/test_distributions.py -v
pytest tests/unit/test_fitter.py -v
pytest tests/unit/test_raytrace.py -v

# Verify gradient cleanliness
python -c "
import jax, jax.numpy as jnp
from tengri.distributions import MyNewDist
d = MyNewDist(...)
g = jax.grad(d.unstandardize)(jnp.array(0.5))
print(f'Gradient: {g}')  # must be finite
"
```

## Conventions

- **Immutability:** Never mutate arrays. Use `jnp.array` or `.at[].set()`.
- **Lazy imports:** Optional deps (nifty, blackjax, optax, arviz) imported inside methods.
- **Parameter names:** High-level uses `sfh_alpha`, `psd_sigma`, `met_logzsol`. Internal uses `alpha`, `sigma_ps`, `log_z`.
- **Units:** Time in years (internal) or Gyr/Myr (user-facing). Wavelength in Angstrom. SFR in Msun/yr.
- **PSD timescale:** `psd_tau_myr` (user) vs `tau_ps` (internal, in years). Conversion: `tau_ps = psd_tau_myr * 1e6`.
- **Metallicity:** `met_logzsol` is solar-relative. SSP grid is absolute `log10(Z)`. Offset: `LOG10_ZSUN = -1.848`.

## Commit Messages

```
feat: new feature
fix: bug fix
refactor: code restructure (no behavior change)
docs: documentation only
chore: maintenance (re-execute notebooks, etc.)
test: adding tests
```
