X-ray Emission
==============

Multi-wavelength X-ray components: X-ray binaries (HMXB + LMXB), and AGN coronae.

- ``plot_xray_sf.py`` — X-ray binary population from star formation rate
- ``plot_xray_agn.py`` — AGN X-ray spectrum and Compton reflection
