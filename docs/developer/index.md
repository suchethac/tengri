# Developer Guide

Resources for contributors and AI agents working on the tengri codebase.

The **Architecture** page describes the package layout, dependency layers,
data flow through the forward model, and the IFT framework design.
**Contributing** covers environment setup, code style, testing, and the PR
workflow. **Internals** documents inference dispatch, fused kernels,
parameter translation, JIT strategy, and known gotchas. The **AI Agent Guide**
provides a quick-start reference for AI assistants working with the code.
