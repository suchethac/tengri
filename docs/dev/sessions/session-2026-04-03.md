## Part 1: API Redesign

### Task 1 — Short-name alias table (`param_translate.py`)

**File:** `src/tengri/core/param_translate.py`

Added `_SFH_SHORT_NAMES`, `_UNIVERSAL_SHORT_NAMES`, and `resolve_short_names()` after the
existing `_REVERSE_ALIASES` dict.

`resolve_short_names(sfh_type, priors)` expands short parameter names to full prefixed names:

```python
# sfh_type can be a string like "tsnorm", "dpl", "field", or "dpl+tsnorm"
priors = dict(log_peak_sfr=Uniform(-1, 2.5), logzsol=Uniform(-2, 0.2))
expanded = resolve_short_names("tsnorm", priors)
# → {"sfh_tsnorm_log_peak_sfr": Uniform(-1, 2.5), "met_logzsol": Uniform(-2, 0.2)}
```

Universal short names (work for any SFH type): `logzsol`, `tau_bc`, `tau_diff`, `dust_slope`,
`psd_sigma`, `psd_tau_myr`, `agn_frac`, `agn_tilt`, `agn_theta`.

SFH-specific short names: `log_peak_sfr`, `alpha`, `beta`, `tau_gyr` (DPL); `t_peak_gyr`,
`duration_gyr` (tsnorm); `psd_sigma`, `psd_tau_myr` (field).

### Task 2 — Method unification in `Fitter.run()` (`fitter.py`)

**File:** `src/tengri/inference/fitter.py`

Added `_DEPRECATED_METHOD_ALIASES` dict at module level. `run()` now:
- Defaults to `method="vi"` (was `"geovi"`)
- Resolves deprecated aliases with `warnings.warn(DeprecationWarning, stacklevel=3)`
- Dispatches 8 canonical names: `vi`, `vi_linear`, `vi_nifty`, `vi_nifty_linear`,
  `mcmc_raytrace`, `mcmc_nuts`, `mcmc_ess`, `mcmc`, `evidence`, `laplace`, `pathfinder`,
  `map`, `auto`
- `"auto"` selects by `spec.n_free`: D≤15 → laplace, D≤50 → vi_linear, else → vi
- `"mcmc"` selects by D: D≤20 → mcmc_nuts, else → mcmc_raytrace
- Sets `result._fitter = self` before returning (enables `refine()`)

Full alias map in `_DEPRECATED_METHOD_ALIASES`: `geovi`→`vi`, `native_geovi`→`vi`,
`mgvi`→`vi_linear`, `raytrace`→`mcmc_raytrace`, `nuts`→`mcmc_nuts`,
`elliptical_slice`→`mcmc_ess`, `nss`→`evidence`, `nifty_geovi`→`vi_nifty`,
`nifty_mgvi`→`vi_nifty_linear`, `geovi_nuts`→`vi`.

### Task 3 — `Posterior._fitter` + `refine()` + `validate()` (`posterior.py`)

**File:** `src/tengri/inference/posterior.py`

`Posterior` is a non-frozen `@dataclass`. Added:

```python
_fitter: object = field(default=None, repr=False)

def refine(self, method: str, **kwargs) -> "Posterior":
    """Re-run inference from current posterior (warm-start)."""
    return self._fitter.run(method, init_from=self, **kwargs)

def validate(self, n_steps: int = 200, **kwargs) -> dict:
    """Short MCMC check. Returns {"mcmc_result", "overlap", "passed"}."""
```

`validate()` runs a short `mcmc_raytrace` run and computes marginal overlap between the
VI/laplace posterior and the short MCMC chains.

### Task 4 — Enhanced `Model.fit()` (`model.py`)

**File:** `src/tengri/core/model.py`

New signature:

```python
def fit(
    self,
    data=None,
    noise=None,
    method: str = "vi",
    data_type: str | None = None,
    *,
    photometry: tuple | None = None,
    spectrum: tuple | None = None,
    init: str | None = None,
    **kwargs,
) -> Posterior:
```

Features:
- `photometry=(flux, noise)` + `spectrum=(flux, noise)` for joint fitting
- `init="map"` runs MAP first and warm-starts VI/MCMC from the MAP result
- Sets `self.fitter_` for later access
- Returns `Posterior` with `._fitter` set
