# Preliminary constraints on SFH burstiness PSD parameters

**Date:** 2026-08-02 · **Branch:** `psd/joint-preliminary` (from
`worktree-hierarchical-psd-spec`, PR #1479) · **Companion:** the PSD paper.

Everything here is measured on this machine. Where a number is inherited from
earlier work it says so. Where a claim is *not* yet supported it says that too.

---

## 1. Setup

One mock population, held identical across every estimator below so the
comparison is like-for-like.

| | |
|---|---|
| Truth | **σ = 0.75 dex, τ = 150 Myr** |
| Redshift | z = 0.1 (fixed) |
| Observable | **10 broadbands** (GALEX + SDSS + 2MASS), photometry only |
| SNR | 20 per band |
| SFH | DPL mean + stochastic field, `n_grid = 16` |
| Field kernel | exact linear-time OU / DRW (`drw_innovations_gp_from_xi`, #865) |
| Shared prior | σ ~ U(0.01, 1.0), τ ~ U(10, 500) Myr |
| Population stream | `jax.random.PRNGKey(0)`, prefix-stable — galaxy *i* is the same galaxy in every run |

Emission lines are generated by `make_population` but **not** declared in the
`Observation`, so they are not in the likelihood. Every result below is
photometry-only. This matters for §4.

---

## 2. Headline

**σ is constrained. τ is not, and neither is σ²τ.**

The population identifies one number — the burst amplitude σ. The correlation
time τ slides almost freely at fixed σ, and because it does, the product σ²τ
inherits that freedom rather than curing it.

This is a statement about the *observable*, not about any one estimator: it
falls out of the shared posterior's own geometry (§3.2) and is consistent with
the independently-measured `n_eff ≈ 3.2` data-constrained field modes for
GALEX+SDSS.

## 3. Two-step estimator (approach B2), N = 4 … 128

From the existing 2048-galaxy Laplace bank `psd_bank_fixed`
(K = 4000 unthinned draws, `min_eigenvalue = 1.0`, zero galaxies rejected).
Re-analyzed, not refit:
`scripts/hierarchical_psd_identified_combination.py`.

### 3.1 Intervals

68% credible intervals; **OK** marks coverage of truth.

| N | σ (truth 0.75) | τ / Myr (truth 150) | σ²τ (truth 84.4) | edge mass |
|---|---|---|---|---|
| 4 | 0.698 – 0.933 **OK** | 12.2 – 30.9 | 7.1 – 23.3 | 0.07 |
| 8 | 0.715 – 0.899 **OK** | 13.0 – 30.9 | 7.5 – 22.7 | 0.04 |
| 16 | 0.765 – 0.950 | 40.2 – 116.3 | 26.0 – 96.7 **OK** | 0.04 |
| 32 | 0.765 – 0.933 | 64.0 – 162.0 **OK** | 39.9 – 126.1 **OK** | 0.02 |
| 64 | 0.966 – 1.000 | 437.9 – 500.0 | 425.5 – 491.5 | **0.79** |
| 128 | 0.983 – 1.000 | 500.0 – 500.0 | 469.5 – 495.9 | **0.99** |

**σ covers truth only at N = 4 and 8**, and misses (narrowly — 0.765 vs 0.75)
from N = 16. Nothing is recovered reliably beyond N = 8 on this bank.

### 3.2 Where the posterior has left the grid

The **edge mass** column — the fraction of posterior mass sitting on the grid
boundary — is the cleanest available failure diagnostic. It is flat at 0.02–0.07
through N = 32, then **0.79 at N = 64** and **0.99 at N = 128**.

That is a sharp truncation event, not a gradual degradation, and it localizes
the handoff's "N ceiling around 32–64" to a single transition. Prefer it to
min-ESS, which is a minimum over a growing sample and can only fall — the
handoff §2 correctly retracts an earlier mechanism built on that column.

**Any row with edge mass above ~0.1 describes where the grid was cut, not the
population.** The N = 64 and 128 rows are reported for completeness only.

### 3.3 Which combination is identified

Eigendecomposing the mass-weighted posterior covariance in (log σ, log τ). The
small-eigenvalue eigenvector is the tightly-constrained direction; its
components are the exponents (a, b) in σ^a τ^b, normalized to a = 1.

| N | τ exponent b | anisotropy | reading |
|---|---|---|---|
| 4 | −0.10 | 3.1 | σ alone |
| 8 | −0.08 | 3.6 | σ alone |
| 16 | −0.09 | 5.5 | σ alone |
| 32 | −0.10 | 5.4 | σ alone |
| 64 | −0.03 | 3.3 | *(truncated — ignore)* |

**b ≈ −0.09, stable across every trustworthy N.** A pure σ²τ power degeneracy
requires **b = +0.5**. It is not close, and the sign is wrong.

So the identified quantity is **σ**, essentially alone. Anisotropy 3–5.5 says
there *is* a degeneracy — it just runs along nearly-constant σ, i.e. τ is the
free direction.

**This corrects the handoff §4b(a)**, which offered σ²τ ("how bursty overall")
as an identified fallback. That was written from the DRW low-frequency
plateau S(f→0) = 4σ²τ, which is correct physics but only becomes the
*identified* combination when the data resolve the PSD break. At z = 0.1 with
10 broadbands they do not, and σ²τ simply inherits τ's freedom — visibly so in
§3.1, where it sweeps 7–23 at N = 4 to 40–126 at N = 32.

σ²τ remains the right measurand for an observable that *does* resolve the
break; the z ≈ 4 rest-UV + Hα regime is the candidate, not this one.

## 4. Why τ is not recoverable here

Two independent measurements, neither new to this run, agree:

- **Mode counting.** GALEX+SDSS constrains `n_eff = 3.21` field modes; +2MASS
  3.43; a full COSMOS 20-band set only 3.95. Adding 8 optical emission lines
  buys ~1 mode (4.17) — but cuts the young-window (<15 Myr) error by 3.8×, so
  lines are worth adding for σ and for recent SFR even though they will not
  rescue τ.
- **Exact-posterior experiment** (handoff §4b): with exact interim draws on the
  real 16-node grid, τ recovers only when essentially **all 16** modes are
  constrained (4 modes → τ 26–34; 16 modes → 128–150 ✓).

A ~3–4 mode observable against a requirement of ~16 is not a tuning problem.
τ is an ill-posed measurand for z = 0.1 broadband photometry, and §3.3 shows
the posterior geometry saying the same thing directly.

## 5. Joint inference

*(§5 is completed below once the joint run lands — see the joint-fit section.)*

The two-step estimator's dominant failure is a **+0.098 nats/galaxy tilt**
toward the grid corner, traced in handoff §4a to dividing by `p_0`, the
grid-averaged interim pushforward, when the draws actually came from a
per-galaxy Laplace Gaussian. Multiplied by N this reaches ~6 nats by N = 64 —
which is exactly where §3.2 sees the posterior leave the grid.

A **joint** fit has no interim prior, no importance weights and no `p_0`, so
that mechanism cannot occur. It is therefore the control that separates two
hypotheses the two-step alone cannot:

- **H1 — the estimator is biased.** Joint recovers τ where two-step does not.
- **H2 — the observable does not identify τ.** Joint fails the same way, and
  §3.3/§4 stand as the explanation.

Driver: `scripts/hierarchical_psd_joint_fit.py`, same `build_model`, same
truth, same `PRNGKey(0)` stream.

## 6. Reproducing

```bash
WT=/path/to/this/worktree
BANK=/path/to/psd_bank_fixed

# Two-step re-analysis (no refitting; ~14 s per N)
PYTHONPATH=$WT/src JAX_PLATFORMS=cpu python \
  scripts/hierarchical_psd_identified_combination.py \
  --bank "$BANK" --ns 4,8,16,32,64,128 --node-chunk 4

# Joint fit
PYTHONPATH=$WT/src:. JAX_PLATFORMS=cpu python \
  scripts/hierarchical_psd_joint_fit.py --n 4 --method mcmc_nuts
```

`PYTHONPATH` is mandatory — the editable install resolves `tengri` to a
different checkout, which may lack `tengri.inference.population`.

## 7. What is NOT established

- **One realization.** Every interval above is a single noise/population draw.
  Coverage across ≥3 realizations is unrun; do not read a single OK as
  calibration.
- **Laplace interim posteriors.** The bank is Gaussian per galaxy. R-hat is
  stored as NaN for it by design (i.i.d. draws make it vacuous), so the
  interim quality gate is the field-scale guard, not a between-chain statistic.
- **No σ two-population separation** (bursty vs smooth) has been run at z = 0.1.
  That, not single-truth recovery, is the FIRE-2/Illustris-style claim the
  companion paper would want.
- **Hierarchical fits still bake the SSP grid** into the compiled program
  (handoff §9): the batched forward is #211. Expect a compile-memory cliff on
  large joint fits until that lands.
