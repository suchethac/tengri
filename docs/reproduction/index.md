# Reproduction

The community has been doing galaxy SED inference for a long time. A
new code should earn trust by reproducing the outputs of the codes
already in use, band by band and component by component, before
claiming anything new.

This section collects those cross-checks. Each entry pairs a tengri
configuration with the closest equivalent in another panchromatic
galaxy SED inference code, runs both on the same mock and the same
real data, and reports where they agree, where they disagree, and
why.
