# SSP library spectral resolution provenance

Per-node instrumental velocity dispersion for the two spectral libraries
tengri's shipped SSP grids are built from (#2518). These are the exact
tables FSPS itself reads (`libfsps/src/sps_setup.f90`, `spec_res(i)`) and
that `python-fsps` exposes as `StellarPopulation.resolutions`; Prospector's
`SpecModel._library_resolution` uses the same array. tengri's shipped grids
(`fsps_*_miles_*.h5`, `fsps_*_c3k_a_*.h5`) are generated by FSPS on these
libraries' own wavelength grids, node for node, so the values below apply
directly with no unit conversion or refitting.

## miles.dat

**Source**: FSPS (<https://github.com/cconroy20/fsps>, commit
`82a873508d500ca353bbb922459bf928498f7a72`, 2024-05-31),
`SPECTRA/MILES/miles.lambda` + `SPECTRA/MILES/miles.res`, concatenated
column-wise unmodified (wavelength [Å], velocity dispersion [km/s]).
5994 rows, 91–1e8 Å.

The MILES library itself measures FWHM = 2.54 Å (Beifiori et al. 2011,
A&A 531, A109; a later re-measurement by Falcón-Barroso et al. 2011, A&A
532, A95, gives 2.51 ± 0.07 Å) constant over its native 3530–7490 Å
window; FSPS's array reflects the 2.54 Å value it was built with. Outside
that window the grid is BaSeL (Lejeune, Cuisinier & Buser 1997, A&AS 125,
229; 1998, A&AS 130, 65) at coarser, approximate resolution.

## c3k_afe0.0.dat

**Source**: same FSPS commit, `SPECTRA/C3K/c3k_afe+0.0.lambda` +
`SPECTRA/C3K/c3k_afe+0.0.res`, concatenated column-wise unmodified.
11149 rows, 100–~1e8 Å.

C3K (Conroy, Kurucz & collaborators) is a synthetic theoretical library;
FSPS's `c3k_a` grid downsamples it onto the BaSeL log(g)-log(T) grid at
R = λ/FWHM = 3000 over 2750–9100 Å, R = 500 over 1000–2750 Å and
9100–24000 Å, R = 250 over 100–1000 Å (`SPECTRA/C3K/readme.md`); FSPS's
array is the exact per-node sigma_v this table implies.

## Sign convention

The velocity dispersion column keeps FSPS's own sign: positive where the
library's own template measurement sets the resolution, negative where
the value is an approximate extrapolation (FSPS: "poorly defined,
approximate, resolution", typically the BaSeL wings outside a library's
native window). `tengri.components.stellar.sps.dsps_wrapper` takes the
absolute value for `SSPData.ssp_resolution_kms` and the sign for the
`ssp_resolution_approximate` mask.

**Format**: plain text, two columns (wavelength [Å], signed velocity
dispersion [km/s]), one row per node, matching the source `.lambda`/`.res`
row order exactly.
